# Homebrew tap for MangaBinder

[Homebrew](https://brew.sh) formula for [MangaBinder](https://github.com/Preygle/manga-downloader):
download manga chapters, convert them to PDF, bind them into volumes and export CBZ.
Works on macOS and Linux.

```bash
brew install preygle/tap/mangabinder
mangabinder web        # opens the browser interface
```

Update with `brew upgrade mangabinder`. The formula follows new
[releases](https://github.com/Preygle/manga-downloader/releases) automatically.
